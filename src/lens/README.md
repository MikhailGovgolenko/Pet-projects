Была решена следующая задача. Найти профиль осесимметричной линзы $z(r)$, образованной поверхностями

$$
z_1(r) = z(r), \quad z_2(r) = -z(r)
$$

из материала с показателем преломления $n$, такой, чтобы параллельный пучок любого диаметра, падающий вдоль оси $z$, сходился в одну точку на оси $z$ на расстоянии $f$ от центра линзы.

Получено следующее нелинейное функционально-дифференциальное уравнение, задающее поверхность $z(r)$:

$$M(r)=t-z\left(\frac{r_i\big|_{r_a=r}}{z_i\big|_{r_a=r}}\left(M(r)-z(r)\right)+r\right).$$

С помощью [cайта](https://mikhailgovgolenko.github.io/Pet-projects/lens) можно смоделировать различные поверхности симметричной линзы.
