<p align="center">

  </a>
</p>

Одна кнопка и одна ссылка на оплату. Добровольный перевод — никаких
товаров, никаких услуг. Ничего лишнего: ни корзины, ни форм, только
переход на платёжную страницу.

## Что внутри

- одна крупная кнопка со ссылкой на платёжную страницу
  (открывается в новой вкладке, `rel="noopener noreferrer"`);
- адрес перевода вынесен в `config.ts` (`config.donation.paymentUrl`);
  при сборке он проверяется парсером `URL` — допускаются только
  `http`/`https`;
- если адрес не задан или остался плейсхолдером, кнопка не ведёт никуда:
  она качается (анимация `wobble`) и показывает примечание
  «Кнопка ещё не подключена» через `aria-live`;
- тексты на русском и английском лежат в `i18n/ru.ts` и `i18n/en.ts`;
- анимации отключаются при `prefers-reduced-motion: reduce`.

## Настройка

Ссылка на оплату задаётся в `src/projects/spend-money/config.ts`:

```ts
export const config = {
  donation: {
    paymentUrl: "https://...",
  },
};
```

Пока `paymentUrl` не задан, страница показывает кнопку-заглушку
с подсказкой вместо перехода.
