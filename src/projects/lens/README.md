
<h1 align="center">Симметричная линза без сферической аберрации</h1>

<p align="center">
  <a href="https://pet-projects.govgolenko.ru/lens">
    pet-projects.govgolenko.ru/lens
  </a>
</p>

Была решена следующая задача. Найти профиль осесимметричной линзы $z(r)$, то есть образованной поверхностями

$$
z_1(r) = z(r), \quad z_2(r) = t-z(r)
$$

из материала с показателем преломления $n$, такой, чтобы параллельный пучок любого диаметра, падающий вдоль оси $z$, сходился в одну точку на оси $z$ на расстоянии $f$ от центра линзы.

Подробнее смотри в [блокноте](https://pet-projects.govgolenko.ru/lens/notes).

С помощью [сайта](https://pet-projects.govgolenko.ru/lens) можно
моделировать различные поверхности симметричной линзы и исследовать
ход лучей через них.
